# PhishGuard Chrome extension (Manifest V3)

Plain JS, no build step. Talks to the local PhishGuard backend (`POST /api/scan`) and links to the dashboard.

## Load unpacked

1. Start the backend (`http://localhost:8000`) and, optionally, the dashboard (`http://localhost:5173`).
2. Open `chrome://extensions` in Chrome (or any Chromium browser).
3. Turn on **Developer mode** (top-right toggle).
4. Click **Load unpacked** and select this `extension/` folder.
5. Pin PhishGuard from the puzzle-piece menu so the badge is visible.

After editing files, press the reload icon on the extension card.

## Features

- **Popup**: current tab URL, "Scan this page" (deep scan), risk bar, verdict (emerald / amber / rose),
  top 3 failed checks, impersonated brand, "Open full report" link to `<dashboard>/scans/{id}`.
- **Auto-scan**: on each completed http(s) navigation (localhost skipped) a quick scan (`deep: false`)
  runs; results are cached per URL for 30 minutes. The badge shows the risk score coloured by verdict
  (`!` if the backend is unreachable).
- **Phishing alerts**: a desktop notification (click opens the report) and, if enabled, a dismissible red
  warning banner injected into the page.
- **Context menu**: right-click any link, choose "Scan link with PhishGuard"; the result arrives as a notification.
- **Options** (right-click the icon, then Options, or the popup's Options link): backend URL, dashboard URL,
  auto-scan toggle, warning-banner toggle. Stored in `chrome.storage.sync`.

## Permissions

- `host_permissions`: only `http://localhost:8000/*` and `http://127.0.0.1:8000/*`.
- `<all_urls>` is an *optional* permission, requested only when you turn on the warning banner
  (needed to inject it into arbitrary pages). A custom backend origin is requested when you save it.
- `tabs` (read the tab URL), `storage`, `notifications`, `contextMenus`, `scripting`.

## Icons

`icons/icon{16,48,128}.png` are generated by `python3 scripts/make_icons.py` (stdlib only).
